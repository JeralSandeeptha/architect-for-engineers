# Fucntional Requirements

These define the specific behaviors, features, and functions a system must perform. They dictate exactly what users or other systems can accomplish with the software

This defines `What the system does`

- `Core Actions`: Actions like creating an account, processing payments, or generating reports.

- `Data Management`: How the system handles inputs, outputs, CRUD (Create, Read, Update, Delete) operations, and calculations.

- `Business Rules`: Specific conditions for operations, such as calculating taxes or validating password strengths.

```js
Example: “The system must allow users to log in using their email and password, and send a reset email if they forget their credentials.”
```

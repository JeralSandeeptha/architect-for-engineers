# Non Fucntional Requirements

Also known as "quality attributes," these describe the general constraints, operational standards, and performance characteristics of the system. They ensure the software provides a good, safe, and reliable user experience

This defines `How well the system performs`

- `Performance`: How fast the system is (e.g., page load times, latency).

- `Security`: How the system protects data (e.g., encryption, access controls).

- `Scalability / Reliability`: System uptime, ability to handle high traffic, and crash recovery processes.

- `Usability`: How intuitive and accessible the software is for the end user.

```js
Example: “The system must be available 99.9% of the time and load all transaction data in under 2 seconds.”
```

---

<br/>

| Feature | Functional Requirements | Non-Functional Requirements |
| :--- | :--- | :--- |
| **Focus** | System features and behavior | System quality and constraints |
| **Description** | What the system must do | How well the system must perform |
| **Visibility** | Directly visible to and actionable by the user | Mostly invisible to the user, but supports the overall experience |
| **Testing** | Validated via feature, unit, and integration testing | Validated via performance, security, and usability testing |
